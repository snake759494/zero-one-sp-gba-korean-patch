# 기술 설명

- GBA 일본판 16 MiB 원본에 적용하며 결과는 32 MiB입니다. 원본 식별은 `release_manifest.json`의 전체 SHA-256을 기준으로 합니다.
- 본편 LZ10 스크립트 132개를 독립 구조 검사합니다. 129개를 번역하고 개발용 진단 자원 3개를 보존합니다. 명령·분기 테이블과 텍스트 구역을 구분합니다.
- 본문 문자는 2바이트 CP932를 기반으로 합니다. 한글 코드 A000..CBFF에 별도 글리프를 배치하고 원래 지원 코드의 동작을 회귀 검사합니다. 갈무리11 Condensed 1,256자 글리프는 원래 비트맵으로 배치합니다.
- 사건·인물·용어 사전은 네 구역을 가진 비압축 컨테이너 세 개입니다. 제목 ID 198개, 설명 분기 430개, 외부 참조 21개를 보존하며 가변 길이 한국어를 재배치했습니다.
- 그림은 BIOS Huffman과 LZ10, 4/8bpp 타일·분리 타일맵·비압축 UI 형식을 처리합니다. 텍스트 영역만 변경하고 원래 팔레트·타일 수·공유 타일을 검사합니다.
- 옵션 첫 행의 네 칸은 x=120/152/184/216을 중심으로 삼습니다. 각 칸의 20픽셀 내부 영역에 네이티브 갈무리7 두 글자를 배치합니다. 글꼴 확대·축소는 하지 않습니다.
- 공개 번역 자료의 `source`는 원본 ROM 또는 압축 해제 자원의 위치·길이·바이트 순서입니다. 사용자의 원본에서 원문을 복원하므로 긴 원문 추출 목록을 공개할 필요가 없습니다.

각 엔진 도구는 이 게임의 원본 해시와 구조를 전제로 합니다. 다른 게임에 주소나 변환 코드를 그대로 적용하지 마세요.
